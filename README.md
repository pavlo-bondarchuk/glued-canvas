# Glued Canvas

**Glued Canvas** — односторінковий вебзастосунок для спільного малювання в реальному часі з кількох пристроїв.

Користувач створює кімнату з коротким 4-значним кодом і може запросити інших учасників за посиланням або QR-кодом. Усі підключені пристрої працюють з одним спільним полотном, бачать курсори одне одного та можуть одночасно малювати й доповнювати композицію.

## Демо

GitHub Pages: https://pavlo-bondarchuk.github.io/glued-canvas/

## Основні можливості

- P2P-мультиплеєр у реальному часі через WebRTC / Trystero
- кімнати з 4-значним кодом
- підключення за прямим посиланням або QR-кодом
- одночасна робота кількох учасників
- live cursors і синхронізація штрихів під час малювання
- автоматична передача поточної композиції новим учасникам
- локальне збереження стану через IndexedDB
- відновлення після перезавантаження сторінки
- Undo / Redo
- очищення спільного полотна тільки ведучим
- захист від відновлення старого snapshot після очищення
- підтримка сенсорних екранів і стилусів
- pressure sensitivity, tilt та coalesced pointer events
- повноекранний canvas із малюванням до самого краю екрана
- українська мова за замовчуванням
- додаткова англійська локалізація з перемикачем UA / EN

## Інструменти

- олівець

- гумка
- м’яка «клячка»

- live preview параметрів інструмента

## Продуктивність

Рендер побудований за інкрементальним принципом: під час `pointermove` обробляється тільки новий сегмент штриха, а готова композиція зберігається у кешованому canvas. Повний replay історії виконується лише під час рідкісних операцій — наприклад Undo / Redo, snapshot, reconnect або повне очищення.

## Запуск

Проєкт не потребує збірки.

1. Завантажте репозиторій.
2. Відкрийте `index.html` через локальний HTTP-сервер або розмістіть файл на будь-якому статичному хостингу.
3. Для мультиплеєра потрібен доступ до інтернету для зовнішніх модулів та WebRTC-сигналінгу.

Наприклад:

```bash
python3 -m http.server 8080
```

Після цього відкрийте:

```text
http://localhost:8080
```

## Мови

Основна мова інтерфейсу — **українська**. Англійська доступна через перемикач `EN / UA`, вибір мови зберігається у `localStorage`.

## Статус

Проєкт розвивається як експериментальний collaborative drawing tool із фокусом на P2P-взаємодію, роботу зі стилусами та використання кількох фізичних пристроїв як єдиного творчого середовища.
